# Ask Me To Do

A private collection of image-editing prompt files and visual reference images. The text files provide reusable instructions for colour variations, image quality, pose, and other requested edits.

## Repository Structure

All files are stored in the repository root.

### General instruction files

| File | Purpose |
|---|---|
| [`4k.txt`](4k.txt) | Base prompt for the requested 4K-style portrait edit |
| [`changes.txt`](changes.txt) | Additional edit requirements, including adjustable straps, sweat/skin detail, and face matching |
| [`pose.txt`](pose.txt) | Pose and framing instructions |
| [`scarf.txt`](scarf.txt) | Instruction to remove scarves and not include a scarf |

## Suggested Workflow

1. Choose a colour prompt, such as `maroon.txt`, `emerald-green.txt`, or `coffee-brown.txt`.
2. Read the selected colour prompt and use it as the colour-specific instruction.
3. Review `changes.txt` for additional edit requirements.
4. Use `pose.txt` when a standing pose and waist-up framing are required.
5. Follow `scarf.txt` to ensure no scarf is included.
6. Consult the reference images where useful.

## Important Notes

- Treat the selected prompt and additional instruction files as separate inputs; combine their requirements when the task calls for them.
- Preserve the reference person's identity and other unchanged features as closely as the editing tool permits.
- Check the selected prompt and all applicable instruction files before starting an edit.
- The reference images are examples, not a replacement for written instructions.
